# BUAA College Code Table

北京航空航天大学系号—学院/书院对照表。

## 文件说明

- `BUAATable.tex`：LaTeX 源文件
- `BUAATable.pdf`：当前版本对照表
- `BUAATable_ACG.pdf`：ACG 修改版本
- `BUAATable_Henan.pdf`：河南相关版本
- `images/`：参考图片和导出图片
- `.vscode/settings.json`：VS Code LaTeX Workshop 编译配置

## 编译环境

- Visual Studio Code
- LaTeX Workshop
- MiKTeX
- XeLaTeX
- latexmk
